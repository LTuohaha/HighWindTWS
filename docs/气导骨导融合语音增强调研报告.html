空气传导（MIC）与骨传导（VPU）信号融合的语音增强技术调研

目标场景：12 m/s 风速风噪  |  输入配置：3 路空气传导 MIC + 1 路 VPU 骨传导  |  调研日期：2026-08-14
多模态融合风噪抑制 TWS / 穿戴通话特征级 / 决策级融合

1. 任务背景与场景挑战

本任务面向户外强风环境下的上行通话语音增强（如骑行、跑步、大风天气佩戴 TWS / 开放式耳机通话）。设备具备 3 路空气传导麦克风（MIC）与 1 路 VPU（Voice Pick-Up，骨传导/振动）传感器。理解两类传感器在该场景下的互补性，是设计融合算法的前提。

1.1 12 m/s 风噪的声学特性

12 m/s 约相当于 6 级风（强风），湍流气流直接冲击麦克风振膜与外壳声孔，产生的气动噪声具有以下关键特性：

  • 低频主导：能量集中在 500 Hz 以下，与语音基频及第一共振峰高度重叠，常规高通滤波会损伤语音低频；
  • 强非平稳性：湍流脉动导致噪声瞬时波动剧烈，噪声谱估计难以收敛，谱减/维纳类方法失效明显；
  • 空间相关性极低：风噪是各麦克风处独立的局部湍流压力脉动，不同麦克风之间的风噪几乎不相关——这意味着依赖空间相干性的波束形成对风噪的天然抑制能力有限（不相关噪声叠加仅获 10·log₁₀N ≈ 4.8 dB@3MIC 的非相干平均增益，且无法形成方向性零点）；
  • 声压级高、易削波：强风下 MIC 可能接近声学过载点（AOP），出现非线性失真；
  • 信噪比极低：风噪 SPL 可达 75~85 dB，而语音仅约 65 dB，输入 SNR 常为负值。

1.2 VPU 骨导信号的特性

VPU 通过拾取说话者颅骨/颌骨振动获取语音，与空气传导路径完全独立：

维度VPU（骨导）MIC（气导）
抗环境噪声天然免疫风噪与空气传播噪声强风下严重污染
有效带宽窄（约 300 Hz ~ 3.5 kHz，高频严重衰减）宽（全频段）
音色自然度闷、失真，无法直接作为输出自然（无噪时）
自身干扰体动摩擦、碰撞、串扰—
与语音同步性仅响应佩戴者本人语音 → 天然 VAD / 参考源含全部环境声

结论：VPU 不适合直接重建语音（带宽受限、音色差），但作为抗噪的语音参考/VAD/低频成分来源价值极高；MIC 提供全频带音质但怕风噪。二者呈强互补，融合的核心问题是"让每种模态只贡献它可信的部分"。

2. 主流融合方案调研

现有气导 + 骨导融合语音增强方案可分为三大类：传统信号处理融合、端到端深度学习融合、以及"传统前端 + DNN 后端"的混合架构。

2.1 传统信号处理融合

① BC 辅助 VAD + 自适应滤波 / 波束形成（Zhou et al., Sensors 2020）

双麦 + 骨导传感器的实时系统：骨导信号对环境噪声不敏感，由其产生高精度 VAD，用于控制自适应噪声对消器（ANC）与自适应阻塞矩阵（ABM）的更新时机（仅在非语音帧更新噪声统计量，避免语音被误消除）；后端接 SRU 轻量网络后滤波，损失采用 SI-SDR。

  • 优点：实时性好、可解释、VPU 利用率精准（只做最擅长的"判断有没有语音"）；
  • 缺点：VPU 只作开关量，未参与频谱级融合，信息利用浅；风噪空间不相关时 ANC/波束形成本身增益受限；
  • 适配要点：多 MIC 扩展只需将双麦波束形成器换成多通道 GSC / MVDR，架构不变。

② BC 作参考信号的非线性 ANC（FLANN，Huang et al., APSIPA 2014）

以骨导信号为参考、气导信号为主输入，用函数链人工神经网络（FLANN）作非线性自适应滤波器，建模骨导→气导的非线性传输映射，从含噪气导信号中恢复语音。

  • 优点：显式建模 BC→AC 映射，VPU 直接参与波形级重建；
  • 缺点：单 MIC 架构，未利用阵列空间信息；自适应滤波对强非平稳风噪跟踪能力弱；BC 高频缺失导致重建高频依赖气导残留。

2.2 端到端深度学习融合

① 双塔时域网络 + 对比学习（BiNet，Li / Yang 等）

两个独立编码器分别将骨导语音与含噪气导语音映射到共享嵌入空间，解码器利用双模态嵌入重建干净语音；双塔间加跳连融合局部与全局特征，并用对比学习正则约束两模态嵌入相似度（实验表明嵌入越相似效果越好）。

  • 优点：两塔结构充分保留各模态内在信息，避免早期拼接导致强模态淹没弱模态；PESQ/STOI 显著优于单模态；
  • 缺点：仅考虑 1 MIC + 1 BC，未涉及多麦阵列；时域网络计算量较大，端侧部署需压缩；
  • 借鉴点：分塔编码 + 中间层融合是处理"带宽/统计特性差异巨大的异构信号"的范式，可直接迁移到 3MIC+VPU。

② 深度平衡多模态迭代融合（DBMIF，2026）

三分支架构（AC 分支 / BC 分支 / 融合分支），多尺度交互编解码骨架上串联迭代注意力模块（IAM）与跨分支门控模块（CBGM）实现双向自适应加权交换，再加"平衡交互瓶颈"学习紧凑稳定的融合表征；目标是在宽 SNR 范围内保持性能一致——AC 在高 SNR 主导、BC 在低 SNR 主导。

  • 优点：显式解决"两模态可信度随 SNR 反转"问题，极适合风噪（SNR 动态范围极大）；下游 ASR 字错误率再降 ≥2.5%；
  • 缺点：结构复杂、训练成本高；公开实现仍以 1AC+1BC 为主；
  • 借鉴点：门控/注意力动态加权是风噪场景融合的关键机制——风噪强度本身波动剧烈，固定权重的融合必然在部分时段失效。

③ 音频 + 振动多模态 DPRNN（VibOmni，耳戴设备）

DNN 做特征提取与初步增强，双向 DPRNN 建模时序依赖；将振动信号（骨导）与音频联合训练，多模态输入作为正则缓解单模态过拟合；内置 SNR 估计器动态调节推理算力。实测 WER 降低约 44%，延迟较 FullSubNet 降低 31 倍。

  • 优点：面向耳戴设备设计，低延迟、有真实佩戴数据验证；SNR 自适应算力分配适合功耗敏感场景；
  • 缺点：非开源；多麦阵列支持未明确。

2.3 传统前端 + DNN 混合架构（本项目基线）

① IVA + GTCRN（H-GTCRN，Interspeech 2025）

本任务参考基线。流程：双通道 STFT → FD-WPE 去混响 → AuxIVA 盲源分离（2 源）→ 按能量选目标源 → 原始双通道复谱(4ch) + IVA 目标/干扰源 log 幅度(2ch) = 6 通道特征 → GTCRN（ERB 压缩 + SFE + 分组双路 RNN）估计复数掩码 CRM。核心思想是用无参数的 IVA 前端先做显式分离，把"初步分离结果"作为额外特征喂给小模型，以极小参数量（~几十 K）在低 SNR 下显著超越纯 DNN。

  • 优点：前端可解释、参数量极小、端侧友好；IVA 天然支持任意通道数（解混矩阵 M×M），扩展 3MIC 路径清晰；
  • 缺点：目标源选择靠能量启发式，强风噪下可能选错；未用 VPU；IVA 迭代有额外时延与算力开销；
  • 本项目任务二即在此架构上扩展 3MIC 并预留 VPU 接口。

② 神经波束形成（MVDR/GEV + DNN 掩码估计）

DNN 估计语音/噪声的时频掩码 → 计算空间协方差矩阵 → 求解 MVDR/GEV 波束形成器 → 可选后滤波。是多麦阵列增强的经典混合范式（如 FaSNet、各类 CHiME 参赛系统）。

  • 优点：空间滤波 + 非线性抑制双重增益，掩码估计鲁棒；
  • 缺点：风噪空间不相关时协方差矩阵接近对角阵，MVDR 退化为通道平均，增益骤降——这是 12m/s 风噪下多麦方案的共性瓶颈；每帧求逆/特征分解算力开销大。

2.4 工业界 3MIC 通话降噪实践（TWS 耳机）

小米 3mic ENC：3 路 AEC → 波束形成聚焦嘴部方向 → 双通路自适应滤波分离出"语音主导通路 + 噪声主导通路" → 双通路送入 AI 降噪模块 + 双通道后处理；配套内麦增强、自适应内外麦映射、风噪检测、风噪抑制四项专门技术，风噪数据单独大规模采集训练。

Bose 和差比风噪检测：无风时语音在两麦上高度相关（和信号能量 ≫ 差信号）；风噪空间不相关时差信号能量骤升——用"和差能量比"实时估计风噪等级，动态调节高通截止频率、波束主瓣宽度与过减因子。

艾为帝江（AI 眼镜）：多麦（2~8 路）+ 麦克风状态检测（低频能量突增 + 过零率异常识别哪些通道正被风噪冲击）→ 按通道污染程度动态调整降噪强度；骑行 8~10 m/s 场景语音可懂度 45% → 82%。

工业界共识：风噪必须"先检测、分通道、再分级抑制"，被风击穿的通道应降权或剔除而非平均使用；这与 IVA 的盲分离选源思想一致，也提示我们 VPU 通道质量同样需要在线评估（体动噪声时段应降权）。

3. 多通道输入的模型结构调整方法

从单/双通道扩展到 3MIC + VPU 的 4 通道输入，模型结构需要在以下几个层面调整（按改动深度由浅到深）：

3.1 输入特征层：通道扩展与归一化

  • 复谱展开拼接：每路 MIC 的 STFT 实部/虚部占 2 个特征通道（3MIC → 6ch），是最直接、信息无损的方式，H-GTCRN 即采用此方式；首层卷积 in_channels 按通道数线性修改即可，网络其余部分不变（通道维在首层被压缩到隐藏维）；
  • 幅度 + 空间特征组合：对每路通道提取 log 幅度，另加通道间IPD（通道间相位差）、ILD（能量差）、GCC-PHAT 特征，显式提供空间线索；注意风噪下相位类空间特征可信度下降，应配合噪声类型条件化使用；
  • 前端分离结果作为特征：WPE/IVA/波束形成的输出（目标源、干扰源）以 log 幅度形式拼入特征，让 DNN 学习"何时信前端、信多少"——这是 H-GTCRN 的核心思想，也是提高多通道利用率性价比最高的手段；
  • 异构通道的尺度归一化：VPU 与 MIC 的能量分布、带宽差异巨大，直接拼接会让强模态主导梯度。应对各模态独立做均值方差归一化 / log 压缩，或对 VPU 做带宽掩蔽（仅保留 300~3500 Hz 有效频带，其余置零/掩码）。

3.2 编码层：共享编码 vs 分塔编码

方式结构适用性
单塔共享编码所有通道拼接后进入同一编码器（H-GTCRN 现状）参数省、通道间交互早
分塔编码（BiNet 式）MIC 阵列一塔、VPU 一塔，各自编码后中间层融合异构模态首选，VPU 高频缺失不会污染共享权重
混合式（推荐）3 路 MIC 共享一塔（同质信号，含 IVA 前端），VPU 独立小塔，在 bottleneck 处门控融合兼顾参数效率与模态差异

3.3 融合层：注意力 / 门控机制

  • 通道注意力（SE 模块）：对输入特征通道做 squeeze-excitation，让网络按帧自适应调整各输入通道权重——可在风噪冲击某路 MIC 时自动降权；
  • 交叉注意力：以 VPU 特征为 Query、MIC 特征为 Key/Value（或反向），显式建模跨模态时频对应；
  • 门控融合（GLU / CBGM）：学习逐时频点的模态混合系数，等价于可学习的"SNR 自适应切换"，是 DBMIF 验证有效的机制；
  • 参考通道选择：掩码统一施加在参考 MIC（如耳内通话麦）上，其余通道只提供信息；参考通道选择逻辑应封装为可配置项。

3.4 序列建模与输出层

  • 序列建模（RNN/DPRNN/Conformer）与通道数解耦，一般无需改动；GTCRN 的分组双路 GRNN 可直接复用；
  • 输出通常为参考通道的复数掩码（CRM）或直接映射谱；多输出头（同时预测语音与噪声）可提供额外监督信号，提高训练稳定性；
  • 训练目标建议 Hybrid Loss（压缩域复谱 MSE + 幅度 MSE + SI-SNR），与原 H-GTCRN 保持一致。

4. 多通道数据利用率：融合策略全景

按融合发生的位置，多通道/多模态融合策略可分为五级，利用率由低到高、实现复杂度也由低到高：

层级策略典型做法优点缺点本场景评级
L0 辅助信息级VPU 不参与重建，只提供控制量 VPU-VAD 控制 ANC/噪声估计更新（Zhou 2020）；VPU 触发风噪模式切换 极简、极稳、实时性最好VPU 频谱信息浪费，上限低 必备基线
L1 信号级波形域直接处理 BC 作参考的非线性 ANC（FLANN）；波束形成后拼接 可解释、无训练强非平稳风噪下跟踪差 可作前端
L2 特征级-早期原始特征拼接进同一网络 所有通道 STFT 实虚部 + log 幅度拼接（H-GTCRN 方式） 实现最简单、交互最早、信息无损 异构模态尺度失衡；通道数 ↑ 首层计算 ↑ MIC 通道间推荐
L3 特征级-中期各模态独立编码后中间层融合 双塔 + 跳连（BiNet）；门控/交叉注意力融合（DBMIF、GLU） 模态差异处理好、可逐时频点动态加权、抗 SNR 反转 结构复杂、训练需平衡两塔 VPU 接入推荐
L4 决策级-后期各路独立增强后按置信度合并 分频段切换（低频用 VPU 重建、高频用 MIC 增强输出）；按 VPU-VAD/SNR 估计在多个增强输出间软切换 各分支可独立优化；失效隔离好 切换边界 artifacts；分支间信息不互补 可作兜底策略

提高多通道利用率的 6 条工程准则（对本项目直接可操作）

  1. IVA 全源利用：3MIC IVA 分出 3 个源，不要只取目标源——把目标源 + 全部干扰源的 log 幅度都拼入特征，干扰源相当于"噪声参考"，帮助网络做差分抑制（任务二代码已实现）；
  2. 原始信号与前端输出并用：永远保留原始复谱特征，让网络可以在前端失效时回退（H-GTCRN 验证有效）；
  3. 风噪按通道检测、按帧降权：用低频能量比/和差比对每路 MIC 打风噪污染分，作为额外特征通道输入，网络学习降权策略；
  4. VPU 三重利用：① 频谱特征（中期融合）② VAD 先验（作为特征或损失掩码）③ 目标源选择参考（用 VPU 与 IVA 各源的相关性选目标源，替代纯能量启发式）；
  5. 损失层面的多通道监督：除参考通道增强损失外，可加 IVA 目标源与干净语音的一致性辅助损失，防止前端退化；
  6. 数据增广覆盖通道失效：训练时随机丢弃/污染单路 MIC 与 VPU，迫使网络不依赖单一通道，推理时通道异常自动鲁棒。

本项目基线		 L1+L2双麦→本项目扩 3MIC较强（IVA 对非平稳鲁棒）优秀（极小参数） 前端可解释、端侧友好、低 SNR 强选源启发式；无 VPU
工业 3mic ENC（小米等） L0~L2 混合3MIC 原生强（风噪检测+分级抑制）优秀 大规模风噪数据训练，工程完备闭源；无骨导模态

6. 本场景适用性评估与推荐架构

6.1 关键判断

  1. 风噪空间不相关 ⇒ 多麦波束形成收益有限，3MIC 的价值更多体现在"多视角冗余 + 盲源分离可分性 + 通道级风噪检测与剔除"，而非方向性滤波；
  2. VPU 是 12m/s 风噪下的决定性模态：它几乎不受风噪影响，其 VAD、低频语音参照、目标源选择依据三项能力恰好弥补 MIC 阵列在强风下的全部短板；
  3. IVA + 轻量 DNN 的混合架构最契合端侧约束：IVA 通道扩展数学上免费（解混矩阵 2×2→3×3），GTCRN 首层改输入通道数即可，参数与延迟增量极小；
  4. 融合必须是动态的：风速、体动都在变化，固定融合权重必然部分时段失效，门控/注意力机制或"风噪分级参数切换"至少取其一。

6.2 推荐总体架构（分两期落地）

第一期：3MIC + IVA + H-GTCRN（本报告配套代码已实现）

3MIC 波形→ STFT→ FD-WPE 去混响→ AuxIVA(3源) 盲分离→ 能量选目标源→ 特征拼接：3MIC复谱6ch + IVA目标/干扰log幅度3ch = 9ch→ GTCRN(ERB+SFE+DPGRNN)→ CRM × 参考MIC → iSTFT

相比原双麦版：IVA 从 2 源扩为 3 源联合分离；IVA 全源（1 目标 + 2 干扰）log 幅度全部入特征，多通道利用率从 6ch 提升到 9ch；输入层 in_channels 参数化，由配置自动推导。

第二期：VPU 接入（接口已预留，三种模式可配置）

VPU 波形→ 带限预处理(300~3500Hz) + STFT→ VPU 特征（复谱+log幅度）⇒ 模式A 特征拼接 / 模式B VPU引导IVA选源 / 模式C 门控融合
  • 模式 A（特征拼接，默认）：VPU 复谱 2ch + log 幅度 1ch 拼入特征 → 12ch，实现最简；
  • 模式 B（选源引导）：用 VPU 与 IVA 各源的时频相关性替代能量启发式选目标源，强风下选源准确率显著提升（VPU 不受风噪污染）；
  • 模式 C（门控融合，进阶）：VPU 经小塔编码后与 MIC 特征在 bottleneck 处 GLU 门控融合，对应 DBMIF 思路的轻量化版本。

6.3 训练数据建议

  • 风噪仿真关键：风噪在 3 路 MIC 上应去相关生成（独立湍流噪声 + 各自低频能量调制），语音则按阵列几何加小时延/衰减保持相干——否则模型学不到真实的可分性边界；
  • VPU 仿真：干净语音经骨导等效滤波（带通 300~3500 Hz、高频滚降）+ 少量体动噪声 + 与 MIC 噪声独立的底噪；
  • SNR 覆盖 -15 ~ +15 dB，风噪占训练噪声 ≥40%（含不同风速档位）；随机通道 dropout 增广；
  • 评估指标：PESQ / STOI / SI-SDR + 风噪段分段 MOS，关注语音段失真与风噪段残留的平衡。
风险提示：① 若 VPU 与 MIC 采样时钟不同步，需先做对齐（硬件同步采样或互相关时延估计），否则中期融合特征错位；② 佩戴松动时 VPU 信号骤降，需在线 VPU 质量检测并自动降级为模式 B/纯 MIC 模式；③ 12m/s 下 MIC 可能削波，训练数据应混入削波样本或在前端加去削波处理。
