1. 核心问题：为什么需要这么多"信噪比"？

所有这四个指标本质上都在做同一件事：衡量估计信号 ŝ 与真实信号 s 的接近程度。但它们在"什么才算误差"这个问题上存在根本分歧。

1.1 朴素思路：直接算差值

最直观的想法：误差 e = ŝ - s，然后看信号能量 vs 误差能量：

SNR = 10 · log10( ||s||² / ||ŝ - s||² )

这就是 SNR（Signal-to-Noise Ratio）。看起来没问题，但看下面两个例子：

例子 A：幅度不同，形状相同
ŝ = 0.5 · s（波形形状完全一样，只是音量小了一半）
→ e = -0.5s，||e||² = 0.25||s||² → SNR = 10·log(1/0.25) = 6.02 dB
明明形状完美匹配，SNR 却只有 6 dB，不合理！
例子 B：把音量调大就能作弊
如果 ŝ = 2s + n（除了噪声外还有放大），则 SNR 可能比 ŝ = s + n 更高。
模型可以靠"放大音量"来刷高 SNR，而不是真正提升分离/增强质量。

核心矛盾：SNR 无法区分"形状匹配"和"幅度匹配"。这驱动了后续指标的演化。

1 SNR — 朴素，但受幅度缩放影响
↓ BSS Eval 工具包引入 SDR，加入滤波/分解
↓ Le Roux 等人发现 SDR 存在滥用问题，提出 SI-SDR
↓ Conv-TasNet 等引入 SI-SNR（与 SI-SDR 等价）

2. 逐个拆解：每个指标的定义与公式

2.1 SNR（Signal-to-Noise Ratio）

最基础 有缺陷
SNR(ŝ, s) = 10 · log10( ||s||² / ||ŝ - s||² )

含义：直接将真实信号 s 作为参考，计算估计信号 ŝ 与 s 的差异能量比。

缺陷：

  • 尺度敏感：ŝ = α·s 时，SNR ≠ ∞（除非 α=1）
  • 可作弊：模型可以放大输出信号来提升 SNR
  • 不关心形状：音量大的信号自动获得更高 SNR

2.2 SDR（Signal-to-Distortion Ratio，BSS Eval 版本）

经典 易被滥用

BSS Eval 工具包（v3.0）将 ŝ 分解为四部分：

ŝ = starget + einterf + enoise + eartif

其中：

  • starget — 目标信号（允许一个 512 抽头的滤波器来匹配）
  • einterf — 干扰信号（来自其他说话人）
  • enoise — 噪声分量
  • eartif — 伪影分量（算法引入的人为噪声）
SDR = 10 · log10( ||starget||² / ||einterf + enoise + eartif||² )

还有子指标：SIR（干扰抑制比）、SAR（伪影比）、ISR（空间失真比）。

⚠️ 关键问题（Le Roux et al., ICASSP 2019）：
BSS Eval v3.0 的 bss_eval_sources 允许用 512 抽头的 FIR 滤波器来匹配参考信号。
这意味着：即使你把所有频率分量都置零，只要滤波器能匹配上，SDR 仍然可以是无穷大。这完全失去了评估的意义。
许多论文报告的 SDR 差值（0.1 dB 量级）实际上可能只是滤波器的随机波动。

2.3 SI-SDR（Scale-Invariant SDR）

推荐 ICASSP 2019

Le Roux 等人提出的修复方案。核心思想：允许对真实信号 s 做一个最优的幅度缩放，再计算误差。

α = argminα ||α·s - ŝ||² = ⟨ŝ, s⟩ / ||s||²
SI-SDR(ŝ, s) = 10 · log10( ||α·s||² / ||α·s - ŝ||² )

等价视角：先找到 s 的最佳缩放版本 α·s，再计算这个缩放版本与 ŝ 的 SNR。

▶ 回到例子 A：ŝ = 0.5·s → α = 0.5 → α·s = 0.5·s = ŝ → 误差为 0 → SI-SDR = +∞ dB ✅
▶ 回到例子 B：ŝ = 2·s + n → α = 2 → α·s - ŝ = -n → 只惩罚噪声，不惩罚幅度缩放 ✅

2.4 SI-SNR（Scale-Invariant SNR）

推荐 Conv-TasNet

Conv-TasNet（Luo & Mesgarani, 2019）中使用的指标，在语音分离/增强领域最流行。公式如下：

starget = (⟨ŝ, s⟩ / ||s||²) · s
enoise = ŝ - starget
SI-SNR = 10 · log10( ||starget||² / ||enoise||² )
🔑 关键洞察：SI-SNR 与 SI-SDR 完全等价。

SI-SDR 的做法：缩放 s → α·s，然后计算 SNR(ŝ, α·s)
SI-SNR 的做法：把 ŝ 投影到 s 方向得到 starget，再计算能量比

α = ⟨ŝ, s⟩/||s||²，所以 α·s = starget，||α·s - ŝ||² = ||enoise||²
两个公式完全一模一样，只是表述方式不同。

4.2 SI-SDR / SI-SNR — 先缩放再比

先消除幅度缩放，再比较形状差异

4.3 向量空间视角

SI-SNR / SI-SDR 的本质：计算 ŝ 在 s 方向上的投影，仅当 ŝ 偏离 s 的方向时才产生惩罚

5. 关键结论：SI-SNR 与 SI-SDR 的关系

SI-SNR ≡ SI-SDR（完全等价）

来证明一遍：

SI-SNR(ŝ, s) = 10 · log10( ||starget||² / ||enoise||² )

其中 starget = (⟨ŝ, s⟩ / ||s||²) · s = α·s，enoise = ŝ - α·s

SI-SDR(ŝ, s) = 10 · log10( ||α·s||² / ||α·s - ŝ||² )

其中 α = ⟨ŝ, s⟩ / ||s||²

∴ SI-SNR(ŝ, s) = SI-SDR(ŝ, s)

唯一的区别是命名历史：
· Le Roux 等人在 2019 年 ICASSP 论文中称之为 SI-SDR（Scale-Invariant SDR）
· Luo & Mesgarani 在 2019 年 Conv-TasNet 论文中称之为 SI-SNR（Scale-Invariant SNR）
· 两者在同一时间独立提出，公式完全一致

现在语音分离领域多用 SI-SDR，语音增强领域多用 SI-SNR，但实际是一回事。

5.1 为什么叫"SNR"而不是"SDR"有区别？

虽然公式相同，但名称的细微差别反映了不同的视角：

  • SI-SNR（SI-Source-to-Noise Ratio）：强调"源"与"噪声"的区分——把投影部分视为"源信号"，正交部分视为"噪声"。
  • SI-SDR（SI-Signal-to-Distortion Ratio）：强调"失真"——把正交部分视为"信号失真"，而非环境噪声。

但在实际使用中，这两个名称完全互换。

6. 实际应用中的陷阱

6.1 陷阱 1：SDR 的滤波器作弊

BSS Eval v3.0 的 bss_eval_sources 允许 512 抽头滤波器。
后果：即使增强信号质量很差，滤波器也能强行匹配，导致 SDR 虚高。
建议：新论文不要再使用 bss_eval_sources 的 SDR，改用 SI-SDR。

6.2 陷阱 2：SI-SDR 在有噪参考中的上界

Jepsen et al. (2025) 发现：当参考信号 s 本身含有噪声时（如 WSJ0-2Mix 数据集），
SI-SDR 存在一个理论上界：SI-SDR ≤ SNRreference
也就是说，即使模型完美分离，SI-SDR 也不会超过参考信号的 SNR。
后果：不同数据集报告的 SI-SDR 值不能直接比较，因为参考信号的干净程度不同。

6.3 陷阱 3：SI-SNR 做训练损失时的中心化处理

项目 [loss.py](file:///d:\Improve\HighWindTWS\iva_hgtcrn_3mic\loss.py#L48-L56) 中的 `si_snr()` 函数包含去均值步骤（中心化），而 HybridLoss 中的 SI-SNR 没有。
中心化会去除 DC 偏移，但也会改变信号的尺度。两种实现的结果不完全等价。

6.4 陷阱 4：负值含义

SNR 为负值不意味着"没有信号"，而是噪声能量超过了信号能量。
在语音增强中，输入 SNR 可能为 -5 dB，增强后达到 10 dB 才是正常水平。
SI-SDR 为 0 dB 意味着信号和误差能量相等（对应约 50% 失真）。

7. 总结：什么时候该用哪个？

场景推荐的指标理由
语音分离评估 SI-SDR Le Roux 论文推荐，无滤波器作弊风险，被广泛接受
语音增强评估 SI-SNR 或 SI-SDR 两者等价，选一个即可。建议补充 PESQ / STOI 等感知指标
训练损失函数 负 SI-SNR 可微、计算快、尺度不变，是 Conv-TasNet 等的事实标准
需要诊断误差来源 SDR + SIR + SAR 需要区分干扰/伪影/噪声时，BSS Eval 的分解仍有用
与历史论文比较 SI-SDR（复现原 SDR 的结果） 许多旧论文报告 SDR，但建议同时报告 SI-SDR 以便公平比较
快速原型/消融实验 SI-SNR 实现简单，一行代码，与训练损失一致
只看整体，不关心细节 SI-SDR 一个数字概括所有失真类型

一句话总结

SNR 看幅度，SDR 拆成分，SI-SDR / SI-SNR 看形状。
忘掉 SNR，忘掉 BSS Eval 的 SDR，只用 SI-SDR / SI-SNR。
