1. 时域损失函数

直接在波形（waveform）上计算损失，不依赖 STFT 等频域变换。优点是端到端、无频域变换的信息损失；缺点是难以直接控制不同频带的感知权重。

1.1 MSE / MAE（波形级）

语音增强 通用
LMSE = || y_pred - y_true ||22
LMAE = || y_pred - y_true ||1

原理：直接最小化预测波形与目标波形之间的 L2 或 L1 距离。MSE 对大误差施加更大惩罚，MAE 对异常值更鲁棒。

优点
简单高效，易于优化；MAE 对异常值更鲁棒。
缺点
与听觉感知弱相关，无法区分不同频率的重要性；MSE 易产生过平滑（over-smoothing）。

1.2 SI-SNR（Scale-Invariant Signal-to-Noise Ratio）

语音增强 语音分离 最常用
SI-SNR = 10 · log10( ||starget||2 / ||enoise||2 )

其中 starget = (y_pred · y_true) / ||y_true||2 · y_true（投影），enoise = y_pred - starget（正交残差）。

原理：先将 y_pred 向 y_true 方向做正交投影，消除幅度缩放的影响（尺度不变性），再计算投影分量与残差的能量比。SI-SNR 值越大越好在训练中通常取负值作为损失。

优点
尺度不变，只关注波形形状；与 SDR 高度相关；语音分离/增强的事实标准。
缺点
纯时域，无法控制特定频带；对相位误差不敏感（均在波形中隐含）。

与 SI-SDR 的关系：SI-SNR 和 SI-SDR 本质上是同一指标，都是尺度不变的信噪比，区别仅在于 SI-SDR 源自信号失真比（SDR）的尺度不变变体，公式完全等价。

1.3 Huber / Berhu 损失（鲁棒回归损失）

语音增强 前沿
Huber: Lδ(e) = { ½e2 若 |e| ≤ δ; δ|e| - ½δ2 若 |e| > δ }
Berhu: L(e) = { |e| 若 |e| ≤ δ; (e2 + δ2)/(2δ) 若 |e| > δ }

原理：Huber 损失在小误差时为 MSE（平方），大误差时为 MAE（线性），兼具两者优势。Berhu 则是反过来：小误差时为 MAE，大误差时为 MSE，对大偏差更敏感。研究表明将 SI-SNR 与 Huber/Berhu 结合可提升 SDR、PESQ 和 STOI。

优点
对异常值鲁棒；比纯 MSE 得到更好的客观指标。
缺点
需要调节阈值 δ；不如 SI-SNR 直观。

1.4 SDR / SIR / SAR（信号失真比）

语音分离 评价指标
SDR = 10 · log10( ||starget||2 / ||einterf + enoise + eartif||2 )

原理：BSS Eval 工具包定义的指标，将估计信号分解为目标分量、干扰分量、噪声分量和伪影分量。SDR 衡量整体分离质量，SIR 衡量干扰抑制，SAR 衡量伪影引入。

优点
分解细粒度，可诊断不同误差来源。
缺点
计算复杂，非完全可微（需近似）；更多作为评估指标而非训练损失。

2. 频域损失函数

通过 STFT 将波形变换到频谱域计算损失，可分别控制幅度和相位，或按频率加权。频域损失与人类听觉感知的相关性通常优于纯时域损失。

2.1 幅度谱 MSE / MAE（Spectral Magnitude Loss）

语音增强 基础
Lmag = MSE( |S_pred|, |S_true| )

原理：对短时傅里叶变换（STFT）后的幅度谱直接计算 MSE 或 MAE。简单直观，但忽略相位信息，且等权处理所有频点。

优点
简单，计算快；直接优化频谱幅度。
缺点
忽略相位；低频能量大，模型偏向低频；与人耳感知弱相关。

2.2 压缩幅度谱损失（Compressed Magnitude Loss）

语音增强 常用技巧
Lcomp = MSE( |S_pred|α, |S_true|α ), α ∈ (0, 1)

原理：对幅度谱进行幂律压缩（如 α=0.3），降低高能量区域（低频）的权重，提升低能量区域（高频）的相对重要性，间接接近人耳听觉特性。

优点
提升高频重建质量；简单有效，广泛使用。
缺点
α 为超参数，需调优；仍忽略相位。

2.3 复数谱 MSE（Complex Spectral MSE / RI Loss）

语音增强 常用
LRI = MSE( Re(S_pred), Re(S_true) ) + MSE( Im(S_pred), Im(S_true) )

原理：分别对 STFT 复数谱的实部和虚部计算 MSE。同时约束幅度和相位，比纯幅度损失更精确。

优点
同时优化幅度和相位；可配合压缩使用（如压缩域复谱损失）。
缺点
实部和虚部误差与感知的相关性不直接。

2.4 对数谱距离（Log Spectral Distance, LSD）

语音增强 评价指标
LSD = (1/F) · Σf ( log|S_pred(f)| - log|S_true(f)| )2

原理：在对数幅度谱上计算 MSE，更接近人对音量的对数感知（韦伯-费希纳定律）。

优点
对数域更符合听觉感知；广泛用于评估。
缺点
log 域在接近零时不稳定；忽略相位。

2.5 Mel 谱损失（Mel-Spectrogram Loss）

语音增强 TTS 常用
Lmel = MSE( Mel(S_pred), Mel(S_true) )

原理：将幅度谱通过 Mel 滤波器组映射到 Mel 尺度（非线性频率刻度，低频分辨率高、高频分辨率低），再计算 MSE。Mel 尺度直接模拟人耳听觉频率选择特性。

优点
与人耳感知高度相关；TTS 和语音增强的标配损失。
缺点
Mel 变换不可逆，丢失相位信息；不适用于需要精确相位重建的任务。

2.6 多分辨率 STFT 损失（Multi-Resolution STFT Loss）

语音增强 TTS 关键技巧
LMR-STFT = Σi λi · ( Lsc(Sipred, Sitrue) + Lmag(Sipred, Sitrue) )

其中 Lsc 是谱收敛损失（Spectral Convergence），Lmag 是对数幅度损失。使用多个不同 STFT 参数（窗长、跳长、FFT 点数）的频谱同时计算损失。

原理：不同分辨率（不同窗长）的 STFT 捕获不同时间-频率分辨率的信息：短窗提供高时间分辨率，长窗提供高频率分辨率。多分辨率组合确保模型同时学习时域精细结构和频域谱包络。

优点
同时捕获时域和频域多尺度信息；HiFi-GAN 等 SOTA 模型的核心损失；无需相位。
缺点
计算量大；需要调节多个 STFT 参数和权重 λ。

3. 感知 / 心理声学损失函数

直接或间接利用人类听觉系统特性来设计损失，使模型在感知质量上表现更好。

3.1 Loud-Loss（等响度曲线加权损失）

2025 前沿 语音增强

原理：基于 Fletcher-Munson 等响度曲线，为不同频带的误差赋予不同的感知权重。人耳对 2-4 kHz 的中频最敏感，对低频和极高频不敏感。Loud-Loss 将频谱划分为子带，每个子带的误差权重由等响度曲线决定。

在 GTCRN 模型上将 MSE 替换为 Loud-Loss，WB-PESQ 从 2.17 提升至 2.93，提升显著。

优点
模型无关，可替换任意频域损失；显著提升感知质量。
缺点
需要预先计算等响度权重；对频带划分方式敏感。

3.2 MetricGAN（指标直接优化）

GAN 语音增强 评价指标

原理：将判别器（Discriminator）的训练目标从"真/假"二分类改为直接预测目标评价指标（如 PESQ、STOI）的分数。生成器通过对抗训练直接优化这些不可微的指标分数。

LD = MSE( D(y_pred), target_score )
LG = LMetricGAN + λ · Lreconstruction
优点
直接优化听感指标；突破传统损失与指标不匹配的问题。
缺点
训练不稳定；需要预训练指标判别器；泛化性受限于训练指标。

3.3 特征匹配损失（Feature Matching Loss）

GAN 语音增强 声码器
LFM = Σi (1/Ni) · || D(i)(y_pred) - D(i)(y_true) ||1

原理：最小化生成样本与真实样本在判别器各中间层特征图之间的 L1 距离。相当于用判别器作为"可学习的感知特征提取器"，迫使生成样本在多个抽象层次上与真实样本匹配。

优点
稳定 GAN 训练；缓解过平滑；提升感知质量。
缺点
增加计算量；依赖判别器质量。

4. GAN 对抗损失函数

在基于生成对抗网络的语音增强/声码器/合成中，判别器的损失函数设计至关重要。

4.1 标准 GAN 损失（Minimax）

GAN 基础
LD = -E[log D(x)] - E[log(1 - D(G(z)))]
LG = -E[log D(G(z))]

原理：标准的二分类交叉熵对抗训练。判别器区分真实和生成样本，生成器试图欺骗判别器。

优点
理论基础成熟。
缺点
训练不稳定，梯度消失；语音增强中效果有限。

4.2 LS-GAN（最小二乘 GAN 损失）

GAN 声码器 常用
LD = E[(D(x) - 1)2] + E[D(G(z))2]
LG = E[(D(G(z)) - 1)2]

原理：用最小二乘损失替代交叉熵，惩罚远离决策边界的样本，梯度更大，训练更稳定。HiFi-GAN、Avocodo 等 SOTA 声码器均使用此损失。

优点
训练稳定；生成质量高；声码器事实标准。
缺点
对超参数敏感。

4.3 Hinge Loss（铰链损失）

GAN 语音增强
LD = E[max(0, 1 - D(x))] + E[max(0, 1 + D(G(z)))]
LG = -E[D(G(z))]

原理：判别器仅对分错的样本提供梯度（位于 hinge 边界内的样本），对已正确分类的样本梯度为 0，提高训练效率。

4.4 相对论 GAN 损失（Relativistic GAN）

GAN 语音增强

原理：标准 GAN 判别真实样本为 1、生成样本为 0，而相对论 GAN 让判别器判断"真实样本比生成样本更真实"的概率，形成对称对抗，梯度更丰富。

优点
生成质量更高；梯度更丰富。
缺点
计算量略增。

5. 语音分离专用损失

语音分离面临一个核心问题：置换歧义（Permutation Problem）—— 模型输出的多个说话人该与哪个标签对应？以下是专门解决此问题的训练策略。

5.1 PIT（Permutation Invariant Training）

语音分离 核心

原理：对模型输出的 C 个估计信号与 C 个真实信号，计算所有 C! 种置换组合下的损失，取最小值作为最终损失。例如 C=2 时有 2 种排列，取损失较小的那个。

LPIT = minπ ∈ Perm(C) Σi L(ŷπ(i), yi)

变体：

  • uPIT（utterance-level PIT）： 在整个句子级别寻找最优排列，保证说话人分配的连续性。
  • tPIT（frame-level PIT）： 在每一帧独立寻找最优排列，更灵活但可能破坏说话人连续性。
  • Soft-minimum PIT： 使用 soft-min 替代硬 min，让所有排列以加权方式参与梯度更新，避免过早陷入局部最优。
优点
端到端，无需额外聚类模块；训练简单；是分离任务事实标准。
缺点
排列数随 C! 增长，C 较大时计算开销大；仅输出固定数量说话人。

5.2 Deep Clustering（深度聚类损失）

语音分离 经典

原理：为每个时频单元学习一个嵌入向量（embedding），使得属于同一说话人的时频单元嵌入尽可能接近，不同说话人的嵌入相互远离。训练时使用亲和力损失（affinity loss）：

LDC = || VVT - YYT ||F2

其中 V 为嵌入矩阵，Y 为 one-hot 标签矩阵。推理时对嵌入向量进行 K-means 聚类，分配时频单元到不同说话人。

优点
可处理任意数量说话人；对未见说话人泛化性好。
缺点
需要后处理聚类；不是端到端；嵌入维度需人工设定。

5.3 Deep CASA（深度听觉场景分析）

语音分离 经典

原理：将分离任务分解为两个阶段：

  1. 同时分组（Simultaneous Grouping）： 在每帧内用 PIT 训练的网络分离不同说话人的频谱。
  2. 时序分组（Sequential Grouping）： 用聚类网络将帧级分离结果跨时间分配给不同说话人。

两个阶段分别优化，最后联合微调。

优点
模拟人耳听觉场景分析机制；在 WSJ0-2mix 上达到 SOTA。
缺点
两阶段训练较复杂。

5.4 说话人条件损失（Speaker-Conditioned Loss）

语音分离 提取

原理：在语音提取（target speaker extraction）中，利用目标说话人的辅助信息（如预注册的说话人嵌入），只计算网络输出中对应目标说话人的损失，避免 PIT。

6. TTS / 声码器专用损失

6.1 Mel 谱重构损失（Mel Reconstruction Loss）

TTS 核心
Lmel = || Mel(y_pred) - Mel(y_true) ||1 或 || · ||22

原理：TTS 模型（如 Tacotron、FastSpeech）的标准损失，将预测的 Mel 谱与目标 Mel 谱做 L1 或 L2 距离。L1 比 L2 产生更清晰的谱图。

优点
直接优化声学特征；与听感相关。
缺点
忽略相位；过平滑问题。

6.2 时长损失（Duration Loss）

TTS 非自回归
Ldur = MAE( d_pred, d_aligner )

原理：在非自回归 TTS（如 FastSpeech、VITS 的时长预测器）中，预测每个音素/字符的时长帧数，与外部对齐器（如 MFA）或注意力对齐获得的时长做 MAE 损失。

优点
控制合成节奏；实现长短可控。
缺点
依赖外部对齐器质量。

6.3 韵律损失（Prosody / Pitch / Energy Loss）

TTS 高级
Lpitch = MAE( f0_pred, f0_true )
Lenergy = MAE( E_pred, E_true )

原理：对基频（F0）和能量进行显式预测与损失约束，控制合成语音的语调起伏和响度变化。常用于增强表现力和自然度。

6.4 先验保持损失（Prior-Preservation Loss）

2024 前沿 TTS
Lppl = E[ || ϵ(Xt, t, μ, p, s; θ') - ϵ(Xt, t, μ, p, s; θ) ||22 ]

原理：在说话人自适应 TTS 微调时，引入预训练数据集中的高质量先验样本，约束模型在微调过程中不忘记先验知识的生成能力，防止过拟合到目标说话人（可能是有噪的 few-shot 样本）。

6.5 声码器多尺度 / 多周期判别器损失

声码器 HiFi-GAN

HiFi-GAN 等声码器使用多个判别器从不同角度评估生成波形：

  • 多尺度判别器（MSD）： 对原始、2×下采样、4×下采样三个尺度的波形做判别。
  • 多周期判别器（MPD）： 将波形按不同周期（2, 3, 5, 7, 11）重排为 2D 矩阵，检测周期模式伪影。
  • 多子带判别器（Avocodo）： 使用伪正交镜像滤波器组将波形分到不同子带分别判别，避免下采样带来的混叠伪影。

每个判别器模块使用 LS-GAN 损失 + 特征匹配损失。

7. 混合损失函数（Hybrid Loss）

实际应用中，单一损失函数往往不够，绝大多数 SOTA 模型采用多组分损失加权组合。

7.1 时域 + 频域混合（最常见）

语音增强 主流
L = λt · LSI-SNR + λf · Lspectral

例如：

  • GTCRN / H-GTCRN： λSI-SNR = 1（取负值）+ 压缩域复谱 MSE + 压缩幅度 MSE（项目中的 HybridLoss）。
  • DCCRN / DCCRN+： 实部 MSE + 虚部 MSE + 幅度 MSE 加权组合。
  • Conv-TasNet： 仅 SI-SNR（纯时域）。

混合损失的优势：SI-SNR 保证波形整体形状匹配，频域损失保证频谱精细结构。

7.2 多分辨率 + 对抗混合

声码器 SOTA
LG = LMR-STFT + λadv · Ladv + λfm · LFM

HiFi-GAN、Avocodo 等声码器的生成器损失：多分辨率 STFT 损失（保证波形保真度） + 对抗损失（提升感知质量） + 特征匹配损失（稳定训练）。

8. 新兴 / 高级损失函数

8.1 STFT 一致性损失（STFT Consistency Loss）

2025 前沿 语音增强

原理：强制增强后的频谱在 STFT 变换前后保持一致性，即 STFT(iSTFT(S_pred)) = S_pred。该损失约束频谱不违反 STFT 的数学约束（如时域信号的过完备性），减少伪影。

8.2 相位感知损失（Phase-Aware Loss）

2025 前沿 语音增强

包括：

  • 瞬时相位损失（IP Loss）： 直接对瞬时相位计算误差。
  • 群延迟损失（GD Loss）： 对相位的一阶导数（群延迟）计算误差，强调相位的变化率。
  • 瞬时角频率损失（IAF Loss）： 对相位的时间导数计算误差。
  • 反缠绕相位损失（Inverse-Wrapping Phase Loss）： 解决相位缠绕问题。

这些损失在 LORT 等模型中综合使用，显著提升相位重建质量。

8.3 扩散模型损失（Diffusion Loss）

2024 前沿 语音增强 TTS
Lsimple = Et, x0, ϵ[ || ϵ - ϵθ(xt, t) ||22 ]

原理：在扩散模型中，训练一个噪声估计器 ϵθ 预测添加的噪声，通过最小化预测噪声与真实噪声的 MSE 来学习数据分布。在语音增强中，将含噪语音作为条件输入，扩散模型学习从噪声到干净语音的逆过程。

8.4 多任务 / 辅助损失

高级
  • VQ 损失（Vector Quantization Loss）： 用于 VQ-VAE 等离散编码模型，包含编码器损失 + 码本损失 + 承诺损失。
  • CTC / Transducer 损失： 用于端到端 ASR，序列级对齐损失，也有时作为语音增强的辅助损失。
  • KL 散度损失： 用于 VAE 变分推理，约束隐变量分布接近先验分布（如 VITS 中）。

9. 损失函数选择指南

场景推荐的损失组合理由

（追求 PESQ）		 Hybrid Loss（SI-SNR + 压缩域复谱 MSE + 压缩幅度 MSE）或 Loud-Loss 时域 + 频域互补，压缩域强调高频，Loud-Loss 直接优化感知质量

（2 说话人）		 PIT + SI-SNR（或 SI-SDR） PIT 解决置换歧义，SI-SNR 端到端优化
语音分离
（未知说话人数）		 Deep Clustering 或 Attractor-based 方法 不限定输出数量，灵活处理可变说话人

关键设计原则

  • 互补性：时域损失关注波形全局形状，频域损失关注频谱精细结构，两者互补。
  • 感知权重：压缩域（α < 1）、Mel 尺度、等响度加权等技巧可提升与听觉感知的相关性。
  • 多尺度：多分辨率 STFT、多尺度判别器、多周期判别器等从不同角度/分辨率约束模型。
  • 稳定训练：特征匹配损失（FM）可显著稳定 GAN 训练，缓解过平滑。
  • 任务适配：语音分离需要 PIT 解决置换问题，TTS 需要显式约束时长和韵律，声码器需要多判别器架构。
