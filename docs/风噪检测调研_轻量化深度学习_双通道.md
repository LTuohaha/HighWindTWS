# 轻量化深度学习风噪检测算法调研（面向双通道语音输入）

> 调研时间：2026-08-31
> 适用场景：TWS 耳机通话链路风噪检测（FreeBuds 单耳 3MIC + VPU 架构），双通道输入，模型需满足端侧实时与低功耗约束
> 结论先行：**当前最有参考价值的三条技术路线为 (1) 双麦低频相干性特征 + 轻量序列模型（检测专用，<100K 参数）；(2) ULCNet/WindNetLite 式子带双编码器 CRN（检测+抑制一体化，~249K 参数 / 73MHz）；(3) "受风通道 + 免风通道"（气导 mic vs VPU）的通道间一致性检测——这是本产品硬件独有的差异化路线。**

---

## 1. 问题定义与风噪物理特性

### 1.1 风噪与声学噪声的本质区别

风噪不是传播声波，而是气流冲刷麦克风膜片产生的湍流压力起伏（"幻影噪声"），其特性决定了检测算法的设计约束：

| 特性 | 风噪 | 语音/普通声学噪声 |
|---|---|---|
| 能量分布 | 集中于低频，主能量通常 <500Hz，可感知成分一般 <4kHz | 语音谐波可延伸至 8kHz |
| 平稳性 | 强非平稳，阵风毫秒级突变 | 准平稳（噪声）/短时平稳（语音） |
| 通道间关系 | 近距离双麦间近似**不相关**（紧密阵列下低频存在有限相干，服从 Corcos 模型） | 传播声波在紧密双麦间**高相干** |
| 频谱形状 | 大致随频率线性衰减（负斜率） | 有谐波结构 |
| 谱细节 | 平滑谱包络、无精细结构 | 有精细结构（谐波、共振峰） |

### 1.2 检测器的角色定位

风噪检测（WND）是风噪抑制（WNR）系统的前端开关，其输出在产品中的典型用途：

1. **通话链路**：输出风噪置信度 / 风 PSD，供降噪前端做低频加权或频带掩码；
2. **ANC 链路**：检测到风噪时关闭/衰减前馈降噪（前馈 mic 受风污染会把风噪"降噪"成放大），切换至反馈为主；
3. **波束/多通道处理**：风噪期间冻结自适应波束系数（风噪违反平面波假设，会污染波束收敛）；
4. **麦克风增益管理**：按风噪强度调整前馈 mic 增益（见 CN114697786A 专利实践）。

> 对本项目的直接意义：SpatialNet 适配链路中，风噪 flag 可作为 v2 方案 NarrowBand 融合的先验——检测到风噪时应降低两颗外部气导 mic 低频的融合权重、提升 VPU 权重（VPU 物理免疫风噪）。

## 2. 传统（非深度）双通道检测基线 —— 深度模型的特征工程基础

深度方案的特征设计几乎全部继承自这一类工作，实现轻量化时尤其如此（特征做得越有效，模型可以越小）。

### 2.1 双麦去相关 / 复相干检测（Kates 谱系）

- **原理**：风噪在两颗近距离麦克风间不相关，而语音等传播声波高相干。计算双通道复相干函数，低频段（如 <1kHz）相干性骤降即判风噪。
- **代表文献**：
  - Kates, "Wind noise reduction for hearing aids", 2008（助听器双麦检测奠基工作）
  - Nelke & Vary, "Dual microphone wind noise reduction by exploiting the complex coherence", ITG Speech Communication, 2014
  - Park et al., "Coherence-based dual microphone wind noise reduction by Wiener filtering", 2016
- **商用验证**：Phonak 助听器双麦克风风噪检测（其 Speech in Wind 功能进一步利用双耳流传输，用受风较小一侧的信号辅助对侧，与本产品"VPU 免风参考"思想同源）。
- **工程注意**：相干值受语音存在干扰——语音活跃段相干被语音拉高，会造成漏检；需要结合能量门限与 SPP（语音存在概率）联合判决。

### 2.2 单通道谱特征检测（Nelke 谱系）

- Nelke, Jax, Vary, "Wind Noise Detection: Signal Processing Concepts for Speech Communication", DAGA 2016：提出三种检测特征——
  1. **短时均值（STM）**：风噪信号均值非零偏移；
  2. **谱形状**：风噪谱近似负斜率线性衰减，对低频谱做负斜率拟合（NSF）；
  3. **能量分布**：风噪能量集中于极低频，计算低频/全带能量比。
  全部实时实现于 20ms 帧、短时谱域，复杂度极低。
- Nelke et al., "Single microphone wind noise PSD estimation using signal centroids", ICASSP 2014：引入"信号质心"特征，兼做检测与风噪 PSD 估计，明确以低复杂度、低内存为设计目标。
- **配套风噪模型**：Nelke & Vary, IWAENC 2014 提出 AR 谱包络 + Markov 链时序统计的风噪生成模型（MATLAB 开源），至今仍是合成训练数据的标准工具之一。

### 2.3 多方法融合判决（专利工程实践）

- **Broadcom US2012/0121100**：双通道多方法检测（每个通道跑 2 种以上检测器，硬/软判决逻辑组合），输出每通道独立的风噪检测信号——工程上对误检/漏检的鲁棒性设计值得借鉴。
- **某 ANC 耳机专利（US20210264893）**：两颗外部 mic 分低/中/高三频段分别计算平均相关性与能量，按"相关性低于阈值 + 能量高于阈值"判强风噪，并结合加速度计运动状态动态调整前馈/反馈滤波器系数——分频段相关性判决是对"全带不相关假设"的细化。
- **国内 ANC 耳机专利（CN，主动降噪控制类）**：利用双耳两只前馈 mic 的频域归一化互相关，平滑后抽取 93.75–781.25Hz 频带判风噪；命中后关前馈、增反馈。频带抽取即风噪主能量区，简单有效。

**小结**：传统方法的共同判别轴是「低频 + 不相关 + 负斜率谱」。深度学习的价值在于：把这些手工特征（及人想不到的非线性组合）交给小网络学习，用监督数据解决阈值标定难、语音/低频噪声混淆、门限场景漂移三大痛点。

## 3. 深度学习检测方案（调研重点）

### 3.1 Qualcomm：端到端 CNN 风噪检测与估计（WO2026151534A1，2025/2026）

当前工业界最贴近"轻量深度检测"目标的一份专利。

- **架构**：原始音频（或其表征）输入由 Conv1d 块（Conv1d + BatchNorm1d + ReLU）堆叠的 encoder，4 个卷积块生成特征图，端到端输出**每个时间步段的风噪概率分布**，与预设阈值比较输出判决；
- **处理粒度**：按 200ms 时间段（16kHz 下 3200 采样点）分段推理，兼顾响应速度与统计稳定性；
- **任务形式**：检测与"风噪估计"（强度/PSD）联合建模，支持 DNN/RNN/Transformer 等多种骨干，但专利主张以 CNN 为主（轻量取向）；
- **输入说明**：专利未限定双通道，但架构与分段策略可直接移植双通道输入（两路波形/谱拼接进 encoder）。

### 3.2 Rhodes（Intel）：RTWD + ANWS，多麦低功耗设备（arXiv:1710.00082, 2017）

智能眼镜场景的多麦风噪检测+抑制系统，是"低功耗可穿戴多麦风噪处理"的早期完整参考：

- **RTWD（检测）**：两组低维信号特征做风噪判别——刻意不用大网络，满足低能耗约束（此部分本质是特征法，但其特征设计面向多通道）；
- **ANWS（抑制）**：神经网络从被风噪污染的谱区域重建佩戴者语音——只在受风噪影响最严重的谱区做重建，避免全带重建的算力浪费；
- **重要结论**：MVDR/GSC 等自适应波束对**扩散性风噪基本无效**（这与本项目差分波束在风噪场景的行为一致，值得在 v2 方案中明确规避策略）；谱减法因风噪非平稳同样失效。

### 3.3 Mirabilii（Fraunhofer IIS / FAU）：多通道风噪检测器与风速估计（博士论文，2023）

学术上最系统的多通道风噪工作，其博士论文（Wind Noise Analysis, Synthesis, and Reduction for Speech Enhancement Using Compact Microphone Arrays）包含三个与本项目直接相关的贡献：

1. **紧密双麦风噪并非完全不相关**：用流体力学的 **Corcos 模型**描述风噪空间相干——相干随频率、风速、麦克风向距、风向各向异性衰减。这解释了为什么"双麦不相关"硬阈值判决在 TWS 的 cm 级间距下会漏检强风噪（低频相干非零）。**对双通道检测器的启示：把互谱相干函数（而非单一相干值）作为特征整体输入网络，让模型自己学相干曲线形状与风噪的映射。**
2. **多通道风噪检测器**：基于语音（传播、相干）与风噪（湍流、弱相干）的空间特性对比设计；
3. **风速/风向估计**：以成对空间相干函数为输入特征的前馈网络回归风速——证明"相干函数特征 + 小 MLP"即可支撑回归级任务，检测任务只会更轻。
   - 相关论文：Mirabilii & Habets, "Spatial Coherence-Aware Multi-Channel Wind Noise Reduction", IEEE/ACM TASLP, 2020（含递归空间相干矩阵估计）；"Wind speed and direction estimation based on the spatial coherence of closely spaced microphones", JASA, 2022。
   - 配套数据生成框架：Mirabilii et al., "Simulating wind noise with airflow speed-dependent characteristics", IWAENC 2022（Corcos 相干可控的多通道风噪仿真器，可直接用于训练数据扩增）。

### 3.4 耳机端低资源场景检测（HiSSNet，ICASSP 2023）

- HiSSNet（Microsoft）：面向降噪耳机的声音事件检测+说话人识别，**层级原型网络（hierarchical prototypical network）**解决少样本类别（各事件类别样本不均衡，风噪等罕见类别尤其如此）；
- 输入为耳机 ANC mic 双通道信号；模型为边缘端设计，验证了"双通道耳机 mic + 轻量分类网络"做开放场景判别的可行性；
- 对风噪检测的启示：风噪正样本（真实强风录音）稀缺，原型网络/度量学习是比普通 softmax 分类更稳的少样本范式。

### 3.5 国内专利中的轻量检测实践

- **CN121751042A（腾达智科技，2025）**：双麦（耳外+耳内，45° 夹角）→ 40 维 Mel 频谱特征 → **嵌入式轻量 CNN（参数量 ≤5KB）** → Softmax 四分类（交通噪声/人声/风噪/安静），按类别动态加载降噪参数。证明了 KB 级 CNN 在耳机 MCU 上做含风噪的场景分类是可行的（虽然其指标为专利自述，未见第三方评测）。
- **CN114697786A**：前馈 mic 采集环境声 → 提取音频特征向量 → 训练好的 DNN 噪声识别模型判风噪 → 存在则按强度调 mic 增益。
- **CN116386654A**：风噪分析采用双通道相关度（按负采样点计数计算相关度，复杂度极低）或低频能量匹配风速；命中后**低频段走 DNN（编码器+RNN+解码器）、高频段走非神经算法**的分治抑制——低频集中算力正是 WindNetLite 同款思想在专利里的体现。

### 3.6 补充：DeWinder（arXiv:2409.06137，2024）——超声感知辅助风噪抑制

用与 mic 同置的超声扬声器发射 20/21kHz 音调，气流的多普勒调制直接反映风速，与 DCCRN/DEMUCS 谱域特征融合后显著改善低 SNR 风噪抑制。**对本项目的启发**：VPU 扮演的就是"独立于气导通道的物理传感器"角色，DeWinder 验证了"气导 + 辅助传感"多模态融合范式的有效性（其 DCCRN 融合结构可参考）。

## 4. 轻量化抑制/重建模型（检测的下游，或检测-抑制一体化）

调研检测算法时必须同时看抑制侧的复杂度基准，因为"检测置信度 + 轻量抑制"往往是一个整体交付物。

### 4.1 WindNetLite（Fraunhofer IIS，arXiv:2507.01821，2025）—— 当前轻量化 WNR 的最佳参照

| 项 | 内容 |
|---|---|
| 任务 | 单通道风噪抑制（wind rejection 直接估计目标 / wind extraction 估计风噪再相减两种范式） |
| 参数量 | **249K** |
| 算力 | **约 73MHz**，≈ 单核 ARM Cortex-A53 的 0.05%；RTF 为 ULCNet 的 40% |
| 结构 | ULCNet 底座 + **双编码器**：低频子带（前 5 个子带，4 层卷积 + GRU128 重点处理）+ 高频子带（3 层卷积 + 平均池化轻量处理）；两阶段掩码：先估实值幅度 mask，再精化为复数 mask；幂律压缩 α（rejection 模式最优 α≈0.5，extraction 模式 α≈1） |
| 数据 | 自录 10h 风噪库 + AudioSet 混合约 200h；测试 VCTK 语音 / MUSDB18 音乐，SNR -20~20dB |
| 指标 | PESQ 2.26 / SI-SDR 12.71（rejection），MUSHRA 与 ULCNet 相当 |

设计要点（可直接迁移到检测模型）：
- **非对称双编码器**：风噪 <4kHz，低频子带给足算力、高频子带严重降采样——检测模型同理，输入可只取低频子带，特征维度大幅下降；
- **逐帧因果处理**：满足嵌入式实时约束（对比 U-Net 系方法只能离线块处理）；
- 注意 Pith 评审指出的局限：α 在测试集上调优、与 ULCNet 的对比并非同任务重训、<4kHz 假设未用自录数据谱统计验证——引用其结论时应留意。

### 4.2 ULCNet（Shetu et al., ICASSP 2024）

"Ultra low complexity deep learning based noise suppression"——子带处理 + 两阶段实/复掩码的通用超低复杂度语音增强框架，WindNetLite 的底座。若本项目后续要做"检测 flag + 风噪抑制"一体化，ULCNet 谱系（含 Shetu et al. IWAENC 2024 低信噪比对比、混合回声+噪声方案）是最成熟的端侧底座。

### 4.3 其他基准（非轻量，仅作性能上界参考）

- U-Net 系：Lee et al., ICCE 2020（单通道户外风噪）；Lin et al., IEEE Sensors Journal 2024（助听器 U-Net + 麦克风结构设计）——2D 卷积、非逐帧，不满足嵌入式约束；
- 双向 LSTM（Hao et al. 谱系）、扩散随机再生模型（arXiv:2306.12867，Interspeech 2023 方向）——质量高但算力重，仅作离线上界；
- Korhonen 等深度 RNN 风噪抑制（助听器，双耳双 mic 输入，JSLHR 2018）：主观可懂度提升的早期循证，说明双通道输入对风噪任务确有增益。

### 4.4 产业方案：Aizip ZenVoice Bone + Bosch BMA550（2024，Best of Sensors Award）

- TWS 骨导 VPU（BMA550，带宽至 2350Hz）+ 轻量神经网络（Zenet 架构）；
- 官方指标：模型内存 60–300KB，处理与内存需求降低 10 倍，可在 -15dB SNR 及 **85dB 风噪**下保持语音（自述指标）；
- **与本产品硬件配置直接可比**（气导 mic + 骨导 VPU），其"骨导低频干净、高频缺失 → 用网络重建高频"的分工与本项目 v2 的 NarrowBand/CrossBand 思路一致，可作为竞品 benchmark。

## 6. 公开数据集与数据构建

| 数据/工具 | 内容 | 对双通道检测的价值 |
|---|---|---|
| **IKS RWTH Wind Noise Database**（Nelke & Vary, IWAENC 2014 配套） | 室内恒定/变化风 × 麦克风间距 2cm/10cm 双麦录音 + 室外真实风，16kHz wav；含 AR+Markov 风噪生成模型 MATLAB 代码 | **唯一现成的双麦风噪库，且 2cm 间距接近 TWS 实际尺寸，优先使用** |
| TUM Wind Noise Dataset（Zenodo 6687982） | 人工生成 + 手机实录风噪样本，137MB | 单通道为主，做数据扩增 |
| ELG 语音/交通/风噪/通用声分离测试集（Zenodo 4279220） | AudioSet+VCTK+DNS 混合测试集 | 负样本/混淆样本来源 |
| Mirabilii Corcos 仿真器（IWAENC 2022） | 风速/风向可控的多通道风噪仿真 | 双通道训练数据的规模化生成 |
| AudioSet "Wind" 类 | 网络风噪标签音频 | 预训练/正样本补充 |

**数据构建建议**（检测器成败的关键在数据而非结构）：
1. 正样本：RWTH 双麦库 + 风扇/风洞自采（覆盖佩戴状态、耳机朝向×风向、行走/骑行相对风速），并用 Corcos 仿真器做风速/风向连续化扩增；
2. 负样本必须覆盖已知混淆项：低频能量大的稳态噪声（公交引擎、地铁、空调）、男性低音语音基音区（60–200Hz 谐波会被"低频+高能量"特征误判）、音乐重低音——这正是 Qualcomm/Mirabilii 用学习法替代固定阈值的核心理由；
3. 半监督标注：可用传统相干法 + 人工校验生成弱标签，再训练网络，缓解逐帧标注成本。

## 7. 面向本项目（单耳 2 外部气导 mic + fb mic + VPU）的设计建议

### 7.1 通道选择：三种"双通道"组合的对比

| 通道组合 | 判别机理 | 优点 | 风险 |
|---|---|---|---|
| A：外部气导 mic1 + mic2（推荐主路） | 双麦低频相干性 + 各自低频能量/谱斜率 | 与文献/专利验证最充分；风噪只影响两通道，信号对称 | cm 级间距下强风低频相干非零（Corcos），需学相干曲线而非单值阈值 |
| B：外部气导 mic + fb mic（耳内） | 耳内 mic 被耳机主体遮挡，受风显著更小 → 通道间能量比异常即风噪 | 天然"受风/半免风"不对称通道，弱风也敏感 | fb mic 信号含耳道语音泄漏与 ANC 重放泄漏，需先去相关处理 |
| C：外部气导 mic + VPU | VPU 拾取颌骨振动，**物理免疫风噪** → 通道间相干性骤降 + 气导低频能量激增即风噪 | 免风参考最干净；VPU <1.2kHz 恰好覆盖风噪主能量区；检测结论可直接复用为 v2 融合的先验权重 | VPU 语音信号谱结构与气导差异大，"相干性"需定义为统计依赖而非简单互相关 |

**建议：主路 A + 辅路 C 做交叉验证。** 两路检测器输出逻辑与（AND 不必严格，可用加权融合），可显著压误检——这正是 Broadcom 专利"多方法软判决组合"的思路。

### 7.2 推荐结构（检测专用轻量网络）

```
外部mic1 ─┐
          ├─ STFT → 取 <2kHz 低频子带
外部mic2 ─┘
          ├─ 特征：双通道低频对数谱 + 互谱相干(MSC, 平滑) + 通道能量比 + 谱斜率
          │        （可选拼接 [气导mic, VPU] 一致性特征）
          ↓
   子带 Conv1D 编码器（2–3 层，核 (1,3)，对应 WindNetLite 低频编码器配置）
          ↓
   单向 GRU（64–128 units，因果逐帧）
          ↓
   FC + Sigmoid → 逐帧风噪软概率 p_wind(t)
          ↓
   迟滞逻辑（挂起 20–50ms + 计数器防乒乓，专利通行做法）→ 硬 flag + 强度分级
```

- **复杂度预算**：检测任务比 WindNetLite 的抑制任务更轻（无解码器、只取低频子带），参考腾达智 5KB 级分类器与 Mirabilii 小 MLP，**目标 <50K 参数 / 个位数 MHz** 是合理且有余量的；
- **输出形式**：输出软概率而非硬判决，供下游（ANC 切换、波束冻结、SpatialNet 前端加权）按各自灵敏度取阈值；
- **与 v2 方案的联动**：p_wind(t) 高时，NarrowBand 融合自动偏置到 VPU 支路；同时触发差分波束系数冻结，避免风噪污染自适应环节。

### 7.3 训练与评测要点

1. 损失：逐帧 BCE + 少量场景级对比（triplet/原型损失可选，处理风噪样本稀缺，参考 HiSSNet）；
2. 评测指标：除 frame-level P/R/F1 外，必须报告**检测延迟**（从阵风起到 flag 置位的毫秒数，ANC 切换要求 <100ms）与**误检率**（男性语音、地铁稳态噪声下的假阳性），这两项比 Accuracy 更能暴露工程问题；
3. 消融：纯手工特征阈值 vs 纯端到端 vs "手工相干特征 + 小 GRU"（预期最后一项性价比最高）。
